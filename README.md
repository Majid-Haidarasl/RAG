# هستهٔ RAG سلسله‌مراتبی و آفلاین آرمان‌رایان

این مخزن یک سیستم پرسش و پاسخ و مدیریت دانش سازمانی است که کاملاً روی یک کامپیوتر محلی و بدون اینترنت کار می‌کند.
مدل‌ها با `Ollama` اجرا می‌شوند و دو مدل اصلی آن `qwen3:8b` و `bge-m3` هستند.
پروژه در ۱۶ فاز ساخته شد و هر فاز یک پوشه در این مخزن دارد.

## نسخهٔ نهایی

آخرین نسخه در پوشهٔ [`rag-phase-16`](rag-phase-16/README.md) قرار دارد؛ شمارهٔ نسخه `1.0.0` و برچسب آن `v1.0` است.
این پوشه همهٔ کد و مستندات را دارد و پوشه‌های قبلی تاریخچهٔ کار هستند.

</div>

```bash
cd rag-phase-16
bash scripts/setup_and_test.sh
```

<div dir="rtl">

راهنمای نصب برای سیستم‌عامل `Ubuntu` و همچنین `Windows 11` نوشته شده است.
روی ویندوز، پروژه داخل `Ubuntu` و روی `WSL 2` اجرا می‌شود.
اسکریپت اصلی با `bash` نوشته شده و برای همین `Git Bash` کافی نیست.
برای اجرا، `Ollama` با مدل‌های `bge-m3` و `qwen3:8b` لازم است و روی ویندوز، نسخهٔ ویندوزی `Ollama` نصب می‌شود.
دستورها را در پوشه‌ای اجرا کنید که ریپو را در آن کلون کرده‌اید.

عددهای مرجع گزارش نهایی روی `Fedora Linux` با `Python 3.15.2` و `Ollama 0.40.17` اندازه‌گیری شده‌اند.
عددهای فاز ۶ تا ۱۱ روی `Ubuntu 24.04.5` با `Python 3.12.3` به دست آمده‌اند.
سیستم‌عامل و نسخه‌ای که در هر فایل `README-phase-NN.md` آمده، مشخصات همان اجراست.

- راهنمای نصب و اجرا برای `Ubuntu` و `Windows 11` در فایل [`rag-phase-16/docs/user-guide.md`](rag-phase-16/docs/user-guide.md) آمده است.
- گزارش نهایی در فایل [`rag-phase-16/docs/final-report.md`](rag-phase-16/docs/final-report.md) آمده است.
- تغییرات نسخه‌ها در فایل [`rag-phase-16/CHANGELOG.md`](rag-phase-16/CHANGELOG.md) ثبت شده است.
