# RAG — هستهٔ RAG سلسله‌مراتبی آفلاین برای آرمان‌رایان

سیستم پرسش و پاسخ و مدیریت دانش سازمانی که کاملاً روی یک کامپیوتر محلی و بدون اینترنت کار می‌کند
(Ollama با `qwen3:8b` و `bge-m3`). پروژه در ۱۶ فاز ساخته شد؛ هر فاز یک پوشه در این مخزن دارد.

## نسخهٔ نهایی

آخرین نسخه در پوشهٔ [`rag-phase-16`](rag-phase-16/README.md) است (نسخهٔ 1.0.0، برچسب `v1.0`).
این پوشه همهٔ کد و مستندات را دارد؛ پوشه‌های قبلی تاریخچهٔ کار هستند.

```bash
cd rag-phase-16
bash scripts/setup_and_test.sh
```

اجرا روی **Ubuntu**، یا روی **Windows 11** داخل Ubuntu در **WSL 2** (اسکریپت bash است و Git Bash کافی نیست).
Ollama با مدل‌های `bge-m3` و `qwen3:8b` لازم است؛ روی ویندوز، Ollama برای ویندوز نصب می‌شود.

- راهنمای نصب و اجرا (Ubuntu و Windows 11): [`rag-phase-16/docs/user-guide.md`](rag-phase-16/docs/user-guide.md)
- گزارش نهایی: [`rag-phase-16/docs/final-report.md`](rag-phase-16/docs/final-report.md)
- تغییرات نسخه‌ها: [`rag-phase-16/CHANGELOG.md`](rag-phase-16/CHANGELOG.md)
