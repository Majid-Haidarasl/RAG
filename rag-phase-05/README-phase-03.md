# فاز ۳ — معماری DDD و مدل دامنه

هستهٔ RAG سلسله‌مراتبی آفلاین · مطالعهٔ موردی **آرمان‌رایان** · ایشو #۳ گیت‌هاب.

این بسته فقط اسکلت دامنه، پورت‌ها و تست واحد است. به Ollama، GPU و اینترنت برای اجرای تست‌ها نیاز نیست. روی ریپو چیزی پوش نمی‌شود؛ خودت فایل‌ها را روی سیستم لینوکست استخراج و تست می‌کنی.

## استخراج داخل ریشهٔ ریپو

فرض: zip در `~/Downloads/rag-phase-03.zip` است و ریپو در `~/RAG`. اگر مسیرهایت فرق دارد، همین دو جا را عوض کن.

```bash
cd ~/Downloads
unzip -o rag-phase-03.zip -d ~/RAG
cd ~/RAG
bash scripts/setup_and_test.sh
```

اسکریپت یک `.venv` می‌سازد، بسته را با `pip install -e ".[dev]"` نصب می‌کند و `pytest` را اجرا می‌کند. در پایان یک بلوک متنی بین دو خط `======== PHASE 3 SUMMARY` چاپ می‌شود. **همان بلوک را کامل کپی کن و بفرست.**

نصب pytest برای بار اول به اینترنت نیاز دارد. خود تست‌ها شبکه را صدا نمی‌زنند.

اگر بخواهی دستی اجرا کنی:

```bash
cd ~/RAG
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
pytest --strict-markers --tb=short
```

یک کانتکست: `pytest -q -m hierarchy`
