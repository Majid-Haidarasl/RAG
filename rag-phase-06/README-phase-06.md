هستهٔ RAG سلسله‌مراتبی آفلاین · مطالعهٔ موردی **آرمان‌رایان** · ایشو #۶ گیت‌هاب.

این بسته روی فاز ۵ سوار می‌شود و بافت `hierarchy` فاز ۳ را گسترش می‌دهد. «سازمان» در ایشو همان ریشهٔ تجمیع `Organization` در این بافت است و بستهٔ تکراری `organization` ساخته نشده است. وابستگی تازه‌ای اضافه نشده است.

## اجرا روی اوبونتو

فرض: zip در `~/Downloads/rag-phase-06.zip` است و کلون ریپو در `~/Desktop/RAG`.

```bash
cd ~/Downloads
unzip -o rag-phase-06.zip -d ~/Desktop/RAG
cd ~/Desktop/RAG
bash scripts/setup_and_test.sh
```

ترتیب اجرا: `pytest`، ورود پیکره، چرخهٔ عمر و تکرار (فاز ۵)، سپس بررسی سلسله‌مراتب. در پایان بلوکی بین دو خط `======== PHASE 6 SUMMARY` چاپ می‌شود. **همان بلوک آخر را کامل کپی کن و بفرست.**

اجرای جدا:

```bash
source .venv/bin/activate
pytest -m registry
python scripts/run_hierarchy_check.py
```

## چه چیزی ساخته شد

- **ثبت لایه‌ها و گره‌ها:** فایل‌های `data/registry/layer-registry.csv` (۵ لایه) و `node-registry.csv` (۲۱ گره) از نمونه‌های فاز ۱ و اسناد سازمانی پیکره، همراه با بارگذار و اعتبارسنج.
- **اعتبارسنج:** قواعد R1 تا R5 فاز ۱، به‌علاوهٔ نوع و لایه، سطح جزئیات، گرهٔ ارجاع، اسناد منبع، وضعیت و الزامات انتقال. همهٔ خطاها یک‌جا گزارش می‌شوند.
- **استثنای Q3:** فقط کتابخانهٔ دانش (L4) می‌تواند زیر مدیریت عامل (L1) باشد. مخزن زیر یک معاونت رد می‌شود.
- **گردش‌کارها:**
  - افزودن گره؛
  - جابه‌جایی گره همراه با زیرشاخه؛
  - بازنشستگی گره و واگذاری دانش آن به جانشین (پیش‌فرض: والد).
- **پرس‌وجوها:** مسیر از ریشه، نیاکان، نوادگان، عمق، برگ‌ها و نزدیک‌ترین نیای مشترک.
- **دامنهٔ بازیابی:** هر گره خودش، زیرشاخه‌اش، اقلام غیرمحرمانهٔ نیاکان و کتابخانه را می‌بیند. اسناد محرمانه فقط برای مالک، هم‌مالک و زنجیرهٔ فرماندهی آن‌ها پیداست.
- **مرز برگ و ارجاع:**
  - مسئلهٔ دو تیم هم‌معاونت به معاونت ارجاع می‌شود؛
  - مسئلهٔ بین معاونت‌ها به مدیریت عامل؛
  - تصمیم رزروشده به هیئت‌مدیره.
- **الزامات انتقال دانش لایه‌ها:** برای هر لایه از L0 تا L4 ثبت شده است: جهت، چه چیزی تحویل می‌شود، حداقل مستندات، تأییدها و بازخورد.
- **نگاشت سند به گره:** `data/registry/document-node-map.csv` هر سند پیکره را به گره‌های مالک، هم‌مالک و توصیف‌شده وصل می‌کند.
