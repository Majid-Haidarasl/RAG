# exports/

Files generated by the kit at run time (not committed; see `.gitignore`).

* `transfer-packages/transfer-packages.sqlite` — Phase 11 store: the latest
  TransferPackage per (cycle, source node) plus every older revision
  (history) and the AI transfer suggestions.
* `transfer-packages/<cycle>/<NODE>.csv` — one package in the key/value CSV
  format (UTF-8, Persian text kept).
* `transfer-packages/<cycle>/latest-packages.csv` — one row per latest package.

`scripts/run_transfer_check.py` rewrites the CSV files from the database on
every run, so they always equal the latest revisions.

* `project-tracking/<cycle>/projects.csv`, `records.csv`, `gaps.csv`,
  `priorities.csv` — Phase 12 tracking tables (UTF-8 with BOM, lists joined
  with `;`). `scripts/run_project_check.py` rewrites them on every run.

* `rfp/<RFP id>/rfp_requirements.csv`, `proposals.csv`, `evaluation.csv`,
  `feedback.csv`, `knowledge_links.csv` — Phase 13 tables (UTF-8 with BOM,
  lists joined with `;`). `scripts/run_rfp_check.py` rewrites them on every run.
