# هستهٔ RAG سلسله‌مراتبی آفلاین — آرمان‌رایان (نسخهٔ ۱.۰.۰)

این پروژه یک سیستم **پرسش و پاسخ روی اسناد سازمان** است که کاملاً روی یک کامپیوتر محلی و بدون اینترنت کار می‌کند.
مدل‌های زبانی با **Ollama** روی همان سیستم اجرا می‌شوند (`qwen3:8b` برای تولید متن و `bge-m3` برای بردار متن).
مطالعهٔ موردی یک شرکت فرضی به نام **آرمان‌رایان** است: ۲۶ سند فارسی و ۲۶ سند انگلیسی، ساختار سازمانی، ایشوها،
پروژه‌ها، RFPها و پیشنهادها.

## سیستم چه کار می‌کند

- اسناد DOCX، DOC و PDF را می‌خواند، تکه‌تکه (chunk) می‌کند و نسخه‌ها و تکراری‌ها را مدیریت می‌کند.
- دانش را در **سلسله‌مراتب سازمان** (لایه‌ها و گره‌ها) نگه می‌دارد و هر پرسش فقط در محدودهٔ همان گره جست‌وجو می‌شود.
- جست‌وجوی ترکیبی (BM25 + بردار) و پاسخ با **ارجاع به منبع** می‌دهد.
- ایشوها و زیرایشوها را با دانش موجود مقایسه می‌کند و مجری مناسب پیشنهاد می‌کند.
- یک **داور** (قاعده‌ای و مدل) کیفیت خروجی‌ها را می‌سنجد.
- بستهٔ انتقال دانش، گزارش پروژه، اولویت ایشوهای کلیدی، RFP و ارزیابی پیشنهادها می‌سازد.
- پرامپت‌ها و تنظیمات را با یک مجموعهٔ مرجع دوزبانه می‌سنجد و بهترین را انتخاب می‌کند.

## شروع سریع

**Ubuntu:**

```bash
sudo apt install -y python3 python3-venv git unzip curl libreoffice-writer poppler-utils
curl -fsSL https://ollama.com/install.sh | sh
ollama pull bge-m3 && ollama pull qwen3:8b
cd ~/Desktop/RAG
bash scripts/setup_and_test.sh
```

**Windows 11:** اسکریپت bash است و داخل **Ubuntu روی WSL 2** اجرا می‌شود (Git Bash کافی نیست). Ollama برای ویندوز
نصب می‌شود و با حالت شبکهٔ mirrored از داخل WSL روی `localhost:11434` دیده می‌شود؛ بقیهٔ فرمان‌ها همان فرمان‌های Ubuntu است.

اسکریپت یک محیط مجازی `.venv` می‌سازد، پروژه را نصب می‌کند، همهٔ تست‌های واحد را با پوشش کد اجرا می‌کند و بعد
بررسی‌های فاز ۴ تا ۱۶ را به ترتیب اجرا می‌کند. آخرین بلوک خروجی `PHASE 16 SUMMARY` است و باید `status: PASS` باشد.
اگر Ollama در دسترس نباشد، مرحله‌های زنده رد می‌شوند و فقط گزارش می‌شوند؛ قبولی به آن‌ها وابسته نیست.

راهنمای کامل نصب و اجرا: [`docs/user-guide.md`](docs/user-guide.md).

## ساختار پوشه‌ها

| پوشه | محتوا |
|---|---|
| `src/rag_core/` | کد اصلی؛ یک بستهٔ پایتون برای هر بافت (bounded context) |
| `tests/unit/` | تست‌های واحد (بدون Ollama، کارت گرافیک یا اینترنت) |
| `scripts/` | اسکریپت اجرای کامل و بررسی هر فاز |
| `config/` | تنظیمات هر بخش (YAML) و پرامپت‌ها |
| `corpus/` | اسناد نمونهٔ آرمان‌رایان (فارسی و انگلیسی) |
| `data/` | ثبت لایه‌ها و گره‌ها، ایشوها، پروژه‌ها، RFPها و مجموعه‌های داوری |
| `eval/` | مجموعهٔ مرجع پرسش و پاسخ، نتیجه‌های ارزیابی و فهرست شواهد |
| `docs/` | مستندات هر فاز، مستندات فنی، راهنمای کاربر و گزارش نهایی |
| `presentation/` | اسلایدهای معرفی و متن دموی زنده |
| `training/` | مطالب آموزشی برای عضو تازهٔ تیم |
| `results/`، `exports/` | خروجی‌های هر اجرا (در مخزن نگه داشته نمی‌شوند) |
