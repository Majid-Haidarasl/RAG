# اسلایدها

| فایل | محتوا |
|---|---|
| `armanrayan-rag-core.pptx` | نسخهٔ نهایی اسلایدها؛ ۱۵ اسلاید فارسی برای معرفی پروژه که در پاورپوینت ویرایش شده است |
| `build_slides.js` | منبع پیش‌نویس قبلی اسلایدها که چیدمان اولیهٔ ۱۲ اسلایدی را می‌سازد |
| `demo-script.md` | متن دموی زنده، قدم‌به‌قدم |

فایل `armanrayan-rag-core.pptx` نسخهٔ نهایی و طراحی‌شدهٔ ارائه است و با رنگ‌های سرمه‌ای و طلایی در پاورپوینت ویرایش شده است.
فونت این اسلایدها `B Nazanin` است. برای نمایش درست، پیش از باز کردن فایل این فونت را روی سیستم نصب کنید؛ در غیر این صورت، نمایش‌دهنده فونت دیگری جایگزین می‌کند و ممکن است فاصله‌ها و شکستن خط‌ها تغییر کند.

اسکریپت `build_slides.js` همان پیش‌نویس قبلی را با فونت `Vazirmatn` می‌سازد و برای بازسازی یا مقایسه نگه داشته شده است.
اجرای این اسکریپت فایل نهایی را بازنویسی می‌کند؛ پس اگر فقط پیش‌نویس را می‌خواهید، پیش از اجرا از فایل نهایی نسخهٔ پشتیبان بگیرید.
برای ساختن پیش‌نویس به `Node.js` نیاز است. در `Ubuntu` یا `WSL` این فرمان‌ها را بزنید:

</div>

```bash
sudo apt install -y nodejs npm
sudo npm install -g pptxgenjs
node presentation/build_slides.js
```

<div dir="rtl">

در ویندوز ۱۱ می‌توانید `Node.js` را از سایت `nodejs.org` نصب کنید و دو فرمان آخر را در `PowerShell` بزنید؛ فرمان نصب در آن‌جا بدون `sudo` اجرا می‌شود.

عددهای اسلایدهای نهایی همان عددهای فایل `docs/final-report.md` هستند؛ اگر گزارش تغییر کرد، اسلایدهای نهایی را هم در پاورپوینت به‌روز کنید.
