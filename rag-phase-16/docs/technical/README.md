# مستندات فنی

این پوشه برای کسی است که می‌خواهد کد را بفهمد، تغییر دهد یا نگه دارد.

| فایل | محتوا |
|---|---|
| [`architecture.md`](architecture.md) | معماری، بافت‌ها (bounded contexts)، لایه‌ها و جریان داده |
| [`operations.md`](operations.md) | اجرا، خروجی‌ها، تنظیمات، افزودن تست و انتشار نسخه |

مستندات جزئی‌تر هر بخش در `docs/phase-03/` تا `docs/phase-15/` است؛ مثلاً مدل دامنه در
`docs/phase-03/domain-model-spec.md`، تکه‌بندی در `docs/phase-04/chunking-spec.md` و ارزیابی پرامپت‌ها در
`docs/phase-14/model-and-prompt-evaluation.md`. فهرست کامل خروجی‌ها در `docs/phase-16/final-checklist.md` است.
